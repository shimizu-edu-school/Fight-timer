# FIGHT TIMER - PWA版

シンプルで使いやすい格闘技用タイマーのPWA（プログレッシブウェブアプリ）版です。

## 🚀 セットアップ方法

このPWA版をデプロイするには、以下の3つのファイルを同じディレクトリに配置してください：

- `index.html` - メインのアプリケーション
- `manifest.json` - PWA設定ファイル
- `service-worker.js` - オフライン対応とキャッシング

## 📱 iPhoneでの使い方

### ホーム画面に追加する方法

1. **Safari** でアプリを開く
2. 下部の **共有ボタン** をタップ
3. **ホーム画面に追加** をタップ
4. 名前を確認して **追加** をタップ

### iPhoneの特徴

- ✅ ホーム画面にアプリとして追加可能
- ✅ 全画面モードで動作（ブラウザのバーが非表示）
- ✅ オフライン利用可能（最初に一度読み込めば）
- ✅ ステータスバーの色をカスタマイズ

## 🔧 主な機能

### 改善された点
- **Service Worker** - オフラインでも利用可能
- **キャッシング** - 一度読み込んだら高速に起動
- **iOS対応** - apple-mobile-web-app-* メタタグ対応
- **ホーム画面追加** - manifest.json対応

### 元々の機能
- ⏱ カスタマイズ可能なラウンドタイマー
- 🔊 複合的な音声フィードバック（gong音、数字読み上げ）
- 🎯 インターバル管理
- 💡 画面スリープ防止機能
- 📱 完全レスポンシブ設計

## ⚙️ 設定項目

- **ラウンド数** - 1～20ラウンド
- **1ラウンド時間** - 1～10分
- **インターバル** - 0～60秒
- **開始前アイドル** - 0～30秒

## 🌐 デプロイ方法

### 一般的なWebホスティング（GitHub Pages, Vercel等）

1. 3つのファイルを同じディレクトリに配置
2. HTTPS環境でホスト（PWAはHTTPS必須）
3. URLにアクセス
4. 「ホーム画面に追加」が表示されればOK

### ローカルテスト

```bash
# Python 3.x
python -m http.server 8000

# Node.js
npx http-server
```

`http://localhost:8000` でアクセス（HTTPでもローカルテストなら動作）

## 📦 ファイル説明

### index.html
- メインのアプリケーション
- Service Worker登録コード含む
- manifest.jsonへのリンク
- iOS対応メタタグ

### manifest.json
- アプリ名・説明
- アイコン（SVG形式）
- 表示設定（スタンドアロンモード）
- テーマカラー設定

### service-worker.js
- キャッシング戦略（キャッシュファースト）
- オフライン対応
- キャッシュの自動更新

## 🔐 セキュリティ

- HTTPS環境で配信してください
- Service Workerはリクエストの改ざんを防止
- Content Security Policyを設定することをお勧めします

## 💡 ヒント

### 古いバージョンから更新する場合
ブラウザのキャッシュをクリアしてから、再度ホーム画面に追加してください。

### 通知機能を追加したい場合
タイマー完了時に通知を送信する機能を追加できます（別途実装が必要）。

### オフライン時の表示
オフラインになると、最後にキャッシュされたバージョンが自動的に表示されます。

## 🐛 トラブルシューティング

### 「ホーム画面に追加」が表示されない
- HTTPS環境で配信されているか確認
- manifest.jsonが正しく読み込まれているか確認
- ブラウザの開発者ツール > Application > Manifest を確認

### 音が出ない
- iPhone: Safari設定で音量を確認
- オーディオコンテキストが正しく初期化されているか確認

### タイマーが動作しない
- JavaScriptが有効になっているか確認
- Service Workerが登録されているか開発者ツールで確認
